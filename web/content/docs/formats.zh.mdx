画廊在交互式详情查看器中使用已发布的 GLB URL。查看器支持鼠标和触控相机操作，且仅在访客打开对应模型的详情页后才加载该模型。

BLEND 是 Blender 源文件格式。仅当记录包含安全的公开 BLEND URL 时，详情页才会显示下载操作。

预览图来自记录的 `preview_url` 和可选的 `preview_urls` 字段。如果 GLB 加载失败，查看器会保留同一条记录的预览图，绝不会用其他资产的图片替代。

除非已发布的记录和未来的实现明确提供，否则画廊不承诺支持 OpenUSD、FBX、OBJ、AR 或仿真就绪（simulation-ready）格式。
