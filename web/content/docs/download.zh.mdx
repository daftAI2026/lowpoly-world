## 下载单个文件

从经校验的目录打开资产。存在对应文件时，使用**下载 GLB**或**下载 BLEND**。文件直接来自公开 Dataset，不经过网站代理。

## 下载多个资产

1. 勾选所需资产。打开预览不会自动加入下载选择。
2. **选择筛选结果**会加入当前结果，不包含未发布资产。
3. 打开**查看下载选择**，检查或移除资产。
4. 导出清单、复制文件链接，或展开**使用 HF CLI 下载**并运行命令。

清单和命令使用固定的 Dataset 提交版本，不使用源 ZIP 哈希或资产版本标签。运行命令前，先安装 [Hugging Face 官方 CLI](https://huggingface.co/docs/huggingface_hub/guides/cli)。网站不会替你执行命令。

文件保存交给浏览器，页面无法确认文件是否已保存。批量选择不会在浏览器中组装 ZIP 或预载全部文件。

无法读取 Dataset 提交版本时，固定版本下载须重试后使用。网站不补造缺失文件。预览图不是源模型。
