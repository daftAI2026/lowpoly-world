## 下载单个文件

从经校验的目录打开资产。存在对应文件时，使用**下载 GLB**或**下载 BLEND**。文件直接来自公开 Dataset，不经过网站代理。

## 下载多个资产

1. 勾选所需资产。打开预览不会自动加入下载选择。
2. **选择筛选结果**会加入当前结果，不包含未发布资产。
3. 点击**已选 N 项**打开审阅，检查、移除或复制链接。
4. 点击**下载**打开确认弹窗，选择文件夹保存或复制固定版本命令。
5. 在**下载任务**查看进度、取消、重试或移除任务。

命令使用固定的 Dataset 提交版本，不使用源 ZIP 哈希或资产版本标签。运行命令前，先安装 [Hugging Face 官方 CLI](https://huggingface.co/docs/huggingface_hub/guides/cli)。网站不会替你执行命令。

## 保存到文件夹

在独立标签页打开在线展厅。支持目录写入的安全窗口会显示**保存到文件夹**。HF 内嵌页面保留文件链接与 CLI，不请求目录权限。点击后选择一个目标文件夹。文件依次流式保存，不在内存中组装 ZIP。每次使用完整 Dataset 提交编号建立版本子目录，不覆盖另一版本。

页面只在写入关闭后计入已保存数量。失败文件列出路径；**停止下载**保留已保存文件。关闭审阅和确认弹窗不会停止已开始的下载。离开工作区会停止任务。重试会重新保存本次选择。

普通文件链接仍交给浏览器保存，不追踪完成状态。不支持目录写入时，使用文件链接或 HF CLI。

无法读取 Dataset 提交版本时，固定版本下载须重试后使用。网站不补造缺失文件。预览图不是源模型。
