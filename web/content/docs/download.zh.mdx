从经校验的画廊记录进入资产详情页。当该记录中存在对应 URL 时，可使用 **下载 GLB**或 **下载 BLEND**。

这些链接直接指向公开 Dataset 中的文件。网站不会代理、重写、上传或打包这些文件。缺失的文件 URL 会显示为 **未提供**。预览图不是可下载的源模型。

如果无法打开 Dataset 文件，请使用详情页上的源链接并在稍后重试。下载失败不会改变已发布的目录记录。
