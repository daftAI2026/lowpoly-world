对本仓库的贡献应聚焦于改进公开网站、其文档或离线测试。请保持改动精简，并说明其对静态构建产物的影响。

请勿提交模型文件、Google Drive 内容、审核记录、凭证或未发布的元数据。未经单独的权利审核与发布者明确批准，请勿向公开 Dataset 添加资产。

在发起拉取请求（Pull Request）前，请基于锁文件安装依赖并运行网站配置的检查项。仓库的 CI 工作流是必跑命令的唯一事实来源。
