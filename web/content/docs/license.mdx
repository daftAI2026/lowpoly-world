[POS]: License 文档；不为模型或图片授予新许可。
[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
*/}

Check the **License** field on each asset detail page before reuse. The website displays the value
published in the catalog. It does not grant rights to an asset or source image.

If a record has no license value, the page shows **Not supplied**. Do not infer a license from the
website, a preview image, or the file format. Ask the publisher for clarification before reuse.

The license for the website's source code is separate from the license for every model, preview,
texture, prompt, and input image. Verify the license in the public repository and the individual
Dataset record.
