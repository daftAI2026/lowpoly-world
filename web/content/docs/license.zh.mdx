在复用前，请先检查每个资产详情页上的 **许可证**字段。网站仅展示目录中已发布的许可内容，不对任何资产或来源图片授予权利。

如果某条记录没有许可值，页面会显示 **未提供**。请勿根据网站本身、预览图或文件格式推断许可。在复用前请向发布者确认。

网站源代码的许可协议与每个模型、预览图、贴图、提示词（prompt）及输入图片的许可协议相互独立。请在公开仓库和对应的单条 Dataset 记录中分别核实其许可。
