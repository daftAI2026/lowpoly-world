Open an asset detail page from a verified gallery record. Use **Download GLB** or **Download
BLEND** when the corresponding URL is present in that record.

The links point to files in the public Dataset. The website does not proxy, rewrite, upload, or
bundle those files. A missing file URL is shown as **Not supplied**. A preview image is not a
downloadable source model.

If the Dataset file cannot be opened, use the detail page's source links and retry later. A failed
download does not change the published catalog record.
