## Single files

Open an asset from the verified catalog. Use **Download GLB** or **Download BLEND** when the corresponding file is published. Files come directly from the public Dataset, not a website proxy.

## Multiple assets

1. Check the assets you need. Opening a preview does not select it for download.
2. Use **Select filtered results** to add the current results, not unpublished assets.
3. Open **Review selection** to inspect or remove items.
4. Export the manifest, copy file URLs, or open **Download with HF CLI** and run the commands.

The manifest and commands pin files to a Dataset commit. This is not the source ZIP hash or the asset's version label. Install the [official Hugging Face CLI](https://huggingface.co/docs/huggingface_hub/guides/cli) before running commands. The website does not run them for you.

## Save to a folder

Open the gallery in a standalone tab. Secure windows with directory-write support show **Save to folder**. The embedded HF page keeps file links and CLI without requesting directory permission. Click it and choose a destination. Files stream sequentially without assembling a ZIP in memory. A subfolder named with the full Dataset commit separates each version from older downloads.

The saved count increases only after a file's write stream closes. Failed paths are listed. **Stop downloads** keeps completed files. Closing the review also stops the current task. Retrying saves the current selection again.

Ordinary file links still hand saving to the browser without tracking completion. Use file links or HF CLI when directory writes are unavailable.

If the Dataset commit cannot be read, fixed-version downloads remain unavailable until you retry. Missing files are never invented. A preview image is not a source model.
