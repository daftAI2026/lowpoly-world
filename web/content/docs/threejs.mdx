Read `glb_url` from a verified catalog record. Use the official `GLTFLoader` from Three.js to load
that public URL into your scene:

```ts
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load(publicGlbUrl, (gltf) => {
  scene.add(gltf.scene);
});
```

Set `publicGlbUrl` from the record. Do not copy a URL from a different asset. Cross-origin access
depends on the Dataset response headers and browser policy. The gallery itself uses
`<model-viewer>` and does not expose a Three.js rendering API.
