1. 打开资产详情页。
2. 当链接存在时，选择 **下载 BLEND**。
3. 在 Blender 中打开下载的文件。
4. 编辑前先检查场景、关联贴图、缩放比例、原点和材质。

网站不会在每个 Blender 版本上测试所有文件。缺少 BLEND URL 意味着发布者未在目录中提供公开的 BLEND 链接。
