The gallery uses a published GLB URL for the interactive detail viewer. The viewer supports mouse
and touch camera controls. It loads a model only after a visitor opens that model's detail page.

BLEND is the Blender source format. The detail page shows a download action only when the record
contains a safe public BLEND URL.

Preview images come from the record's `preview_url` and optional `preview_urls` fields. If a GLB
fails to load, the viewer keeps the same record's preview image. It never substitutes another
asset's image.

The gallery does not claim OpenUSD, FBX, OBJ, AR, or simulation-ready support unless a published
record and a future implementation explicitly provide it.
