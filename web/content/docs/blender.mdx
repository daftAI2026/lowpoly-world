1. Open an asset detail page.
2. Select **Download BLEND** when the link is present.
3. Open the downloaded file in Blender.
4. Check the scene, linked textures, scale, origin, and materials before editing.

The website does not test every file with every Blender release. A missing BLEND URL means the
publisher did not supply a public BLEND link in the catalog.
