## 2026-11-03: Original tokens and one selection group

The UI now uses the supplied light, dark, and shadow tokens directly, without custom color blends. Documentation code inherits page colors instead of adding a separate syntax palette. The toolbar drops the sort menu and groups one tri-state select-all checkbox with the selection count. Clear-all is available inside the review. Downloads, sidebar filters, and preview capabilities remain.

## 2026-11-03: Action placement and full-row targets

Downloads and preferences move to the desktop top-right actions. Select-all sits next to view controls. The toolbar has more space above cards, and the asset contribution entry is temporarily removed. Preview controls use three equal columns, file actions stay at the bottom, and metadata disclosure rows are clickable across their full width. Resize affordances appear on hover or keyboard focus.

The taxonomy now covers explicit object families and compound names, including camera bags and tree houses. These are website browsing categories, not changes to Dataset records, new model releases, or quality certification.

## 2026-11-03: Download workflow and compact layout

The selection count opens anchored review. Download opens a separate confirmation dialog. A persistent Downloads panel provides progress, cancellation, and failed-file retries. Closing a popup does not stop started tasks. Folder saving begins only after the user clicks and chooses a destination.

Asset names and IDs share a compact row. The toolbar aligns with search, side previews remain sticky, and results use the native main-panel scroll. Docking uses an icon menu; identity and copy actions sit in the name menu. This website update does not publish models.

## 2026-11-02: Second model release

The Dataset adds 155 reviewed static models, bringing the published catalog to 165. GLB, Blender sources, and four model-rendered views were checked for each added asset. Models use CC BY 4.0; third-party reference photographs and private source records are not included.

## 2026-11-02: Bottom preview sizing

The bottom preview now sizes the 3D canvas to the available pane height, keeping the model and camera controls visible. Files and metadata scroll in their own column. Left and right docking retain the same viewer; standalone asset pages keep their existing layout.

## 2026-11-02: Official control components

Fumadocs continues to provide navigation, documentation, and asset cards. Gallery controls now reuse official shadcn Base Nova components on Base UI, including forms, popovers, collapsible sections, view toggles, and resizable panels. The handwritten resize handle has been removed.

Both libraries share the existing theme. Source URLs, snapshot hashes, and limited visual adaptations are recorded in the code repository. Asset behavior and the published model count do not change.

## 2026-11-02: Asset workspace

The gallery and documentation use separate Fumadocs layouts. Asset browsing adds mosaic and index views, three thumbnail sizes, shareable filter state, independent download selection, fixed-version manifests and CLI commands, and a preview that docks left, right, or below the results.

The expanded preview stays inside the application and returns to the same results. One viewer remains mounted when moving or expanding it. No AI search, RTX media, or simulation controls are implied. This website update does not publish additional models.

## 2026-11-02: First model release

The public [Dataset](https://huggingface.co/datasets/daftAI2026/lowpoly-world-assets) contains 10 individually reviewed models under CC BY 4.0. Each asset includes GLB, BLEND, preview images, and version metadata. Third-party reference images are excluded.

The existing gallery reads the new catalog without a website rebuild. Unreviewed assets remain private. This release does not certify engineering or simulation accuracy.

## 2026-10-31: Bilingual gallery

The static website is live in English and Simplified Chinese. It provides catalog browsing, model details, a 3D viewer, downloads, and 10 help topics in both languages.

HF serves prebuilt files. It does not run a website server or a remote build. Website code uses the [MIT license](https://github.com/daftAI2026/lowpoly-world/blob/main/LICENSE).

## Release boundaries

Dataset snapshots and website deployments have separate histories. Publishing models updates the catalog; it does not deploy website code. The catalog is the source of the current model count.
