Contributions to this repository should improve the public website, its documentation, or its
offline tests. Keep changes small and describe their effect on the static output.

Do not commit model files, Google Drive content, review records, credentials, or unpublished
metadata. Do not add an asset to the public Dataset without separate rights review and explicit
publisher approval.

Before opening a pull request, install from the lockfile and run the website's configured checks.
The repository's CI workflow is the source of truth for required commands.
