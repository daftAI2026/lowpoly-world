Lowpoly World is a library of low-poly 3D models. Browse online, inspect a model in 3D, and download GLB or Blender source files.

## Choose an entry

- [Hugging Face Dataset](https://huggingface.co/datasets/daftAI2026/3d-assets): browse previews and metadata in Data Studio, or open individual files.
- [Online gallery](https://huggingface.co/spaces/daftAI2026/gallery): search models, use the interactive 3D viewer, and download files.

## Find a model

Open **Assets**. Search by name or asset ID, then narrow the results by category, file format, tags, or triangle count. Switch between **Mosaic** and **Index**, or choose a thumbnail size. Open a model card to inspect it without leaving the desktop results. On a phone, the card opens a separate asset page.

The breadcrumb returns to **All assets**. Remove individual filter chips or clear all filters. Shared URLs preserve search, filters, view, preview, and download selection.

## Preview and download

Drag the model to rotate it and scroll to zoom. Use **Reset view**, **Auto-rotate**, or **Fullscreen** when needed.

Move the preview left, right, or below the results. **Expand preview** opens a larger workspace; **Back to results** restores the results. Opening a preview does not add it to the download selection.

Choose **Download GLB** for a portable 3D file, or **Download BLEND** to edit the native source in Blender. Downloads come directly from the public Dataset.

## Check before reuse

Read the model's license, version, and published quality information. A preview is not an engineering or simulation certification. Missing fields are shown as **Not supplied**.

Use the **Hugging Face** icon in the header to open Data Studio and the original public files. Read **License**, **Use in Blender**, or **Use in Three.js** for the next steps.
