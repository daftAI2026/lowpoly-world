Lowpoly World is a static browser for records published in the Hugging Face Dataset
`daftAI2026/3d-assets`. The website reads the public catalog and does not store model files.

## Browse published records

The gallery reads `catalog/v1/latest.json`, downloads the immutable snapshot it names, and checks
the snapshot SHA256, schema, record count, unique IDs, and Dataset URLs before display.

Use search, category facets, format and tag filters, or triangle-count bands. The gallery sorts the
verified snapshot in the browser and virtualizes visible rows. It does not invent example records.

## Open one asset

Open a record from the gallery to view its GLB, download available files, and inspect public
metadata. The detail route uses a static path and an `id` query parameter.

## Empty and error states

If the Dataset has no `latest.json` pointer, the gallery shows its first-release empty state. If a
request or validation check fails, the gallery shows a failure state and a retry action.
