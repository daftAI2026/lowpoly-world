## 2026-11-03：原始主题与单一选择组

主题直连用户提供的明暗颜色与阴影，移除额外混色覆盖。文档代码继承页面颜色，不再引入独立语法色板。工具栏移除排序下拉，全选三态框与已选数量合为一组，清空全部选择只在审阅内提供。下载任务、左侧筛选和预览能力保持。

## 2026-11-03：动作分层与整行点击

下载任务与偏好进入桌面右上动作区，全选移到视图组前。工具带与卡片增加间距，贡献资产入口暂时移除。预览的三个视角动作等宽，文件按钮固定在底部。元数据折叠标题整行可点，分栏拖拽提示只在悬停和聚焦时显示。

分类词表补齐明确物体名称与复合短语，修正相机包、树屋等修饰语误命中。网站展示分类不改写 Dataset 原字段，也不代表新增模型或质量验收。

## 2026-11-03：下载流程与紧凑排版

多选计数打开锚定审阅，下载按钮另开确认弹窗。下载任务独立显示进度、取消与失败重试；关闭弹窗不停止已开始的任务。目录保存只在用户点击并选择目标后执行。

资产名称与编号紧凑同排。工具带对齐搜索行，左右预览独立吸附，结果列表使用原生主面板滚动。预览停靠改为图标菜单，编号与复制动作归入名称菜单。本次更新不发布模型。

## 2026-11-02：第二批模型发布

Dataset 新增 155 个已审核静态模型，公开目录累计 165 个。新增资产均已核对 GLB、Blender 源文件和四张模型渲染图。模型采用 CC BY 4.0，不包含第三方参考照片或私人来源记录。

## 2026-11-02：下方预览适配

下方预览按面板可用高度适配 3D 画布，模型和视角按钮完整可见。文件与元数据在右列单独滚动。左右停靠保留同一查看器，独立资产页保持原有布局。

## 2026-11-02：统一官方控件

导航、文档和资产卡继续复用 Fumadocs。展厅表单、弹层、折叠、视图切换和可调整分栏统一复用官方 shadcn Base Nova 的 Base UI 版本。手写拖拽分隔条已移除。

两家组件共用现有主题。代码仓记录官方来源、快照摘要与有限的外观适配。资产功能和已发布模型数量不变。

## 2026-11-02：资产工作区

展示与文档采用独立的 Fumadocs 布局。资产浏览新增网格、列表、三档缩略图、可分享的筛选状态、独立下载选择、固定版本清单与 CLI 命令。预览支持左侧、右侧和下方停靠。

展开预览仍在应用内，返回后恢复同一结果。移动和展开保持一个查看器，不代表增加 AI 检索、RTX 媒体或仿真能力。本次网站更新不新增模型发布。

## 2026-11-02：首批模型发布

[公开 Dataset](https://huggingface.co/datasets/daftAI2026/3d-assets) 已发布 10 个逐件审核的模型，采用 CC BY 4.0。每个资产包含 GLB、BLEND、预览图和版本信息，不包含第三方参考图。

现有展厅直接读取新目录，无需重建网站。未审核资产仍保持私有。本次发布不证明工程或仿真精度。

## 2026-10-31：双语展厅上线

静态网站已提供英文和简体中文页面，包含资产浏览、模型详情、3D 查看器、下载，以及 10 个帮助主题的中英版本。

HF 只托管预构建文件，不运行网站服务器或远端构建。网站代码采用 [MIT 许可](https://github.com/daftAI2026/lowpoly-world/blob/main/LICENSE)。

## 发布边界

Dataset 快照与网站部署分别保留历史。发布模型会更新目录，不会部署网站代码。当前模型数量以公开目录为准。
