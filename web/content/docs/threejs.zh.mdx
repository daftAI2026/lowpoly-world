从经校验的目录记录中读取 `glb_url`，并使用 Three.js 官方的 `GLTFLoader` 将该公开 URL 加载到你的场景中：

```ts
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load(publicGlbUrl, (gltf) => {
  scene.add(gltf.scene);
});
```

请从该记录中设置 `publicGlbUrl`，切勿复制其他资产的 URL。跨域访问取决于 Dataset 的响应头和浏览器策略。画廊本身使用 `<model-viewer>`，并不对外暴露 Three.js 渲染 API。
