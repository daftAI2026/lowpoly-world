Lowpoly World 是用于浏览 Hugging Face Dataset `daftAI2026/3d-assets` 中已发布记录的静态网站。网站仅读取公开目录，不存储模型文件。

## 浏览已发布记录

画廊会读取 `catalog/v1/latest.json`，下载其指定的不可变快照，并在展示前校验快照的 SHA256、结构（schema）、记录数量、唯一 ID 以及 Dataset URL。

你可以使用搜索、分类筛选、格式与标签筛选器或三角面数区间进行筛选。画廊在浏览器端对经校验的快照进行排序，并对可见行进行虚拟化渲染。网站不会虚构示例记录。

## 打开单个资产

从画廊中打开一条记录即可查看其 GLB、下载可用文件并检查公开元数据。详情路由使用静态路径和 `id` 查询参数。

## 空状态与错误状态

如果 Dataset 没有 `latest.json` 指针，画廊会显示首次发布前的空状态。如果请求或校验检查失败，画廊会显示失败状态并提供重试操作。
