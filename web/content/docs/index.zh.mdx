Lowpoly World 是低多边形 3D 模型库。你可以在线浏览、交互预览，并下载 GLB 或 Blender 源文件。

## 选择入口

- [Hugging Face 数据集](https://huggingface.co/datasets/daftAI2026/3d-assets)：在 Data Studio 查看预览和元数据，或打开单个文件。
- [在线展厅](https://huggingface.co/spaces/daftAI2026/gallery)：搜索模型、使用 3D 查看器并下载文件。

## 查找模型

打开**模型库**，按名称或资产编号搜索，再通过分类、文件格式、标签或三角面数缩小范围。打开模型卡片即可查看详情。

## 预览与下载

拖动模型可以旋转，滚动可以缩放。需要时使用**复位视角**、**自动旋转**或**全屏**。

选择**下载 GLB**可获取通用 3D 文件，选择**下载 BLEND**可在 Blender 中编辑原生源文件。下载直接来自公开 Dataset。

## 复用前检查

阅读模型的许可、版本和已发布质量信息。预览不构成工程或仿真认证。缺失字段显示为**未提供**。

顶部 **Hugging Face** 图标可打开 Data Studio 和原始公开文件。后续可阅读**许可协议**、**在 Blender 中使用**或**在 Three.js 中使用**。
