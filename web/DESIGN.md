# Lowpoly World Design System

## 1. 产品与视觉方向

只有 HF Dataset 与 Static Space 应用两个交付。
同一应用内，展示与文档是两个独立入口，共用官网 Spacious 外壳。
展示以查找和预览模型为主，不混入文档树。
不显示重复的大标题，语义 h1 仅向辅助技术提供。
原生搜索位置改放模型搜索，不重复展示文档搜索。
宽屏使用侧栏输入，手机使用原生搜索位的 shadcn 弹层。
两者共用 URL 查询，不增加第二个搜索状态。
主区工具宽屏收为一排，计数与选择在左。
网格、列表与三档缩略图采用 shadcn 图标分组。
大小直接点选，不再使用下拉框。
选择计数与唯一三态框成组；不显示排序下拉。
工具带与原生侧栏搜索带对齐，窄屏自然换行。
模型页侧栏不放“模型库／使用文档”导航行。
页面互跳复用原生右上角图标链接，紧邻语言入口。
文档侧栏只保留真实正文树。
仅选中分类后，条件区显示可返回父级的路径。
条件区紧贴结果工具栏，不保留空白路径行。
文档直接使用 Fumadocs 官网 Spacious 与配套 Page。
展示直接复用 Spacious 布局、侧栏、移动抽屉和主面板。
用官方 full 与宽度变量扩展接口占满主内容区。
不再设置 1400px 上限，不自建 header 或侧栏壳。
筛选通过原生 custom link 插槽进入侧栏。
模型页没有章节目录，不为其保留空列。

交互参考 NVIDIA SimReady Central 的实际工作区。
实测其预览可停靠右侧、左侧或结果下方，并可展开。
不能把它概括成固定三栏，也不照搬英伟达品牌外观。

## 2. 颜色

用户最新紫色 OKLCH 明暗 token 是唯一色板。
只替换颜色，保留既定字体、0.5rem 圆角与间距。
FU 使用官方 shadcn 适配，通用控件读取同源 token。
原始色板与阴影值均直接采用用户输入。
业务别名只直连已有 token，不生成额外混色。
面板边线使用 border，控件边线使用 muted-foreground。
明暗主色和 FU 颜色均不另行覆写。
仅保留必要的原生透明状态与遮罩。
文档使用 Shiki none 主题，代码继承页面前景。
不引入额外代码调色板或彩色语言图标。
FU 只调整主面板0.5px线宽，不改布局几何。
默认使用浅色，原生主题选择跨页面保存。
文档原生 System 选项仅在主动选择后跟随系统。
HF 使用官方黄色 SVG，模型材质与源预览不染色。
不引入 NVIDIA 黑黄主题、标识或专有字体。

## 3. 字体与排版

英文使用本地 Inter，中文使用思源 SC 网页子集。
思源子集按 OFL 改名字族，系统字体最后回退。
等宽内容使用本地 Geist Mono。
文档保留官方排版；资产自有文字为 12、14、20px。
资产名称换行，不靠截断掩盖狭窄面板。
保留各字体 OFL 原文，运行期不请求 Google 字体。

## 4. 原生组件

文档仅在 DocsShell 内调用官方 Spacious。
展示首页与独立资产详情使用 GalleryShell。
导航、外链、语言和文档搜索复用原生组件。
资产卡复用官方 shadcn Card，与展厅控件统一。
展厅动作、表单、折叠和分栏复用官方 shadcn Base Nova。
只采用 Base UI 版本，不混入 Radix。
按钮不再拼接 Base UI 原语和 FU buttonVariants。
筛选树、偏好弹层和分隔条不自写交互实现。
16 个组件的官方 URL 与摘要见 registry.sources.json。
官方源码只适配导入、图标和既定外观约束。
边线 0.5px，控件 40px，不增加装饰动效。
紫底白勾与卡片紫边对应下载选择。
当前预览只用中性边线，避免混成下载勾选。
FU 与 shadcn 同向读取用户 token，不生成第二套色板。
卡片勾选采用 20px 字形与内移的 40px 透明点击区。
未选边线使用 muted-foreground，不遮挡缩略图边角。
原始 MIT 许可随构建托管。
业务组件只组合官方控件与真实资产状态。
就地预览复用 AssetDetails，不另写一套 viewer 或元数据。

## 5. 布局与功能

左侧筛选由原生侧栏承载，主面板只有浏览工作区。
浏览工作区包含结果与可关闭的预览，不是固定三等分。
宽屏支持右侧、左侧或下方预览。
左侧预览在主面板内换序，不增加第二套筛选栏。
下方工具栏合为一行，画布填充面板余高。
左右停靠时，结果由原生主面板自然滚动。
列表不与预览共用固定高度，预览独立吸附。
底部停靠保留可调分栏，文件与元数据单独滚动。
卡片名称与编号同排，窄卡自然换行，不预留空行。
预览名称、导航、图标停靠、展开与关闭对齐同一栏。
编号和复制动作进入名称菜单，不再占整行。
指针和方向键调整侧栏宽度或下方高度。
展开在应用内放大同一 viewer，返回恢复原结果。
展开舞台按可用高度缩放，视角控件保持可达。
网格与列表共用行虚拟化，网格提供三档缩略图。
列数按卡片最小宽度计算，不用旧六列上限限制全屏。
分类面包屑回到全库，不伪造供应商品牌。
分类使用稳定英文 ID 与双语名称，来源别名先归并。
明确名称补充分组；不明确的名称保留未分类。
仅渲染实际存在的分类，不改原始 Dataset 字段。
格式、三角面数、标签、尺寸使用可折叠选项。
统一 CC BY 4.0，不提供冗余许可筛选。
不显示存储来源，不把工具归因伪装成分类。
筛选条件逐项移除；偏好控制筛选项与预览条件。
下载任务和偏好进入FU原生右上动作插槽。
窄屏回落到结果工具带，只挂载一份任务入口。
全选与数量入口合为一组，位于视图组前。
只有一个真实三态框，数量入口不含装饰勾。
半选点击转为全选，全选点击清除当前结果。
清空全部选择只在审阅内，不在工具带另放叉。
默认按编号排列，保留旧链接排序参数兼容。
工具带与结果增加8px间距，搜索中心对齐不变。
暂不展示贡献资产入口。
URL 保存查询、筛选、视图、密度、预览与下载选择。
历史与语言切换从同一 URL 契约恢复状态。
下载勾选独立于当前检查资产。
全选明确指向筛选结果，不包括待审资产。
选择计数打开锚定审阅，不在结果内插入面板。
审阅提供缩略图、移除、清空、复制链接和下载按钮。
下载按钮打开独立Dialog，提供目录保存和固定版本命令。
下载任务另由Popover显示计数、进度、取消和重试。
队列归工作区，进度只在任务视图订阅。
关闭审阅或Dialog不取消已交给队列的任务。
只有取消动作或离开工作区才停止任务。
批量下载使用真实 Dataset commit，不使用源文件 SHA。
普通文件链接不追踪落盘，不显示虚假完成进度。
仅独立安全窗口显示目录 API 动作，点击后才选择目录。
HF 内嵌页面保留链接与 CLI，不申请目录权限。
文件按完整 Dataset commit 分目录，流式保存不整包驻留内存。
写入流关闭后才计完成，失败列入状态，支持停止。
不支持目录 API 的浏览器保留文件链接和 CLI。
关闭预览保留筛选、排序和结果位置，并归还焦点。
前后项采用当前筛选顺序，边界不循环。
被筛掉的选中资产仍可检查，但不伪装为结果内项目。

卡片保留独立详情 URL，修改键和窄屏不拦截链接。
手机使用原生侧栏抽屉与独立详情页。
不把筛选、结果与预览挤成三栏。
预览停靠不重挂载当前 viewer，切资产才更新载荷。
同一页面只挂载选中模型，列表不批量创建 WebGL。

## 6. 边界与深度

保留 FU 文档几何和通用 class，主题变量按用户设定。
资产区边线为 0.5px，圆角取现有 token。
停用原生网格列过渡，收起侧栏时即时重新排列。
指针展开面板使用 250ms ease-out 位移与透明度。
键盘、筛选、勾选与布局尺寸变化保持即时。
减少动态偏好禁用上述缓动，不重挂载 viewer。
元数据五个折叠标题整行命中，最小高度48px。
视角动作使用三等分网格，窄面板允许文字换行。
预览文件入口固定在底栏，不随事实区滚走。
分栏拖拽提示居中，仅在悬停或键盘聚焦显示。
GLB 在访问者浏览器中渲染，静态 Space 不申请 GPU。
没有关节、运动或仿真素材，不展示对应按钮。
不把普通模型旋转称作 RTX 渲染或物理认证。

## 7. 文案与许可

保持中英键对齐，不使用中点分隔符或冗余解释。
NVIDIA 仅提供结构和交互参考，本轮未复制其源码。
不将线上压缩 bundle 引入网站。
未新增 Chakra、推理服务、搜索数据库或 GPU 依赖。
未来复用具体源文件须单独保留对应许可和版权。
模型、私人报告与生产工具不进入网站 Git。

## 8. 响应式与访问性

验证 320、390、768、1024、1440px。
宽屏开关预览只改变对应 URL 状态，不丢失搜索。
窄屏卡片应进入同语言独立详情页。
修改键保留新标签行为；预览宽度可用方向键调整。
验证关闭后焦点、前后项和一个已载入 viewer。
文档侧栏仅出现在文档页，两个入口均保留 HF/GitHub。

## 9. 后续修改契约

上述适用浏览能力构成完整验收范围。
AI 检索、RTX 媒体与仿真不属于当前数据能力。
每次发布须验证构建、直链与实际 HF 托管。

先复用现有能力，再扩展业务工作区。
不能以套文档壳代替设计模型展示。
新增媒体功能以真实目录字段和载荷为前提。
Dataset 发布和网站部署继续独立。
